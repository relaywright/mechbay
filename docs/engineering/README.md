# Engineering log

How MechBay was built and what went wrong along the way. Private working
notes stay private; these are curated.

  context, the alternatives we turned down and the consequences.
- [Post-mortems](postmortems.md): root-cause write-ups of the bugs worth
  learning from, each with the test or check that guards against a repeat.
- [Changelog](../../CHANGELOG.md): what shipped in each release.
- [Release checklist](../release-checklist.md): every public claim and the
  source it is checked against before a release.
